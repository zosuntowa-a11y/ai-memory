## 1. 利用者・家族向けのお知らせ文

---

### 1-1 イベントのお知らせ

**使う場面：** デイサービスや施設のイベント告知文を作りたいとき

**プロンプト：**
```
デイサービスの〔イベント名〕について、利用者さんとご家族向けのお知らせ文を作成してください。
条件：
・日時：〔日時を記入〕
・内容：〔内容を記入〕
・参加費：〔無料 / 〇〇円〕
・持ち物：〔記入〕
・雰囲気：やさしく、安心感のある文章
・文字数：400字程度
```

**入力してはいけない情報：** 利用者の氏名・個人情報

**出力後に確認すること：**
- 日時・内容に間違いがないか
- 施設名・担当者名は自分で追記する
- 外部に送る前に担当者が内容を確認する

---

### 1-2 休業・変更のお知らせ

**使う場面：** 施設の休業日や変更事項を伝えるお知らせを作りたいとき

**プロンプト：**
```
デイサービスの〔変更内容〕について、利用者さんとご家族向けにお知らせ文を作成してください。
条件：
・変更内容：〔詳細を記入〕
・変更日：〔日付〕
・対応方法：〔記入〕
・問い合わせ先：〔担当部署のみ、個人名不要〕
・トーン：丁寧でご迷惑をおかけする表現を含める
```

**入力してはいけない情報：** 担当職員の個人情報、内部事情の詳細

**出力後に確認すること：**
- 制度・ルールに関わる内容は必ず担当者に確認
- 法的な案内が必要な場合は専門家に相談

---

### 1-3 季節のご挨拶文

**使う場面：** 年賀状・季節の便りを作りたいとき

**プロンプト：**
```
介護施設からご家族に向けた〔季節〕のご挨拶文を作成してください。
条件：
・温かく、感謝の気持ちが伝わる内容
・施設での日々のケアへの感謝や、ご家族への安心感を伝える
・文字数：200〜300字程度
・個人名は入れず、「〔施設名〕スタッフ一同」で締める
```

**入力してはいけない情報：** 特定の利用者の情報・エピソード

**出力後に確認すること：**
- 施設名・年号を自分で追記する
- 表現が施設のカラーに合っているか確認

## 2. 社内向け案内文

---

### 2-1 会議・研修の案内文

**使う場面：** 社内向けの会議や研修の案内文を作りたいとき

**プロンプト：**
```
社内向けに〔会議・研修名〕の案内文を作成してください。
条件：
・日時：〔日時を記入〕
・場所：〔場所を記入〕
・対象：〔対象者〕
・内容：〔概要を記入〕
・出席確認方法：〔方法を記入〕
・締め切り：〔日付〕
・トーン：丁寧だが親しみやすい社内向けの表現
```

**入力してはいけない情報：** 職員の個人情報

**出力後に確認すること：**
- 日時・場所・担当者名は自分で追記・確認する

---

### 2-2 マニュアル・手順の案内文

**使う場面：** 新しい手順やルール変更を職員に伝えたいとき

**プロンプト：**
```
以下の手順について、職員向けにわかりやすい案内文を作成してください。
手順の概要：
〔手順の大まかな流れを箇条書きで記入〕
条件：
・初めて見る職員にも分かりやすくする
・重要なポイントは太字や箇条書きを使う
・トーン：丁寧だが簡潔に
```

**入力してはいけない情報：** 利用者情報・施設の機密事項

**出力後に確認すること：**
- 手順・ルールの内容が正確かを担当者が確認
- 法令・規定に関わる内容は必ず専門家が確認

## 3. 文章の言い換え

---

### 3-1 硬い文章をやさしく言い換える

**使う場面：** 書いた文章が硬すぎると感じたとき

**プロンプト：**
```
次の文章を、〔利用者さん・ご家族・職員〕に伝わりやすいように、
やわらかく丁寧な表現に直してください。

文章：
〔言い換えたい文章を貼り付ける〕
```

**入力してはいけない情報：** 個人名・個人情報を含む文章

**出力後に確認すること：**
- 意味・内容が変わっていないか確認する

---

### 3-2 トーンを調整する

**使う場面：** 丁寧すぎる・カジュアルすぎると感じたとき

**プロンプト：**
```
次の文章のトーンを、〔もっと丁寧に / もう少しカジュアルに〕調整してください。
対象読者は〔ご家族 / 職員 / 利用者さん〕です。

文章：
〔調整したい文章を貼り付ける〕
```

**入力してはいけない情報：** 個人名・個人情報

**出力後に確認すること：**
- 調整後のトーンが目的に合っているか確認する

---

### 3-3 長い文章を短くまとめる

**使う場面：** 書いた文章が長くなりすぎたとき

**プロンプト：**
```
次の文章を、〔100字 / 200字〕程度に要点をまとめてください。
重要な情報は落とさないようにしてください。

文章：
〔短くしたい文章を貼り付ける〕
```

**入力してはいけない情報：** 個人情報を含む文章

**出力後に確認すること：**
- 要点が正確に残っているか確認する
- 削除された情報で必要なものがないか確認する

## 4. 報告文の整理

---

### 4-1 業務報告の下書き

**使う場面：** 業務報告書の文章を作りたいとき

**プロンプト：**
```
以下の内容をもとに、業務報告書の文章を作成してください。
・実施した業務の概要：〔記入〕
・課題や気づき：〔記入〕
・次回への対応策：〔記入〕
条件：
・個人名や個人情報は含めない
・第三者が読んでも内容が分かるように書く
・簡潔に、箇条書きも使って読みやすくする
```

**入力してはいけない情報：** 利用者・職員の個人情報

**出力後に確認すること：**
- 報告内容が事実と一致しているか確認する
- 担当者・管理者が最終チェックをする

---

### 4-2 ヒヤリハット報告の整理

**使う場面：** ヒヤリハット報告を整理・文章化したいとき

**プロンプト：**
```
以下のヒヤリハット情報をもとに、報告書用の文章を整理してください。
・発生状況：〔個人名・個人情報を除いた状況の説明〕
・原因（推定）：〔記入〕
・対応内容：〔記入〕
・再発防止策：〔記入〕
条件：
・個人名は使わず「利用者A」「職員B」などで表記する
・事実と推定を区別して書く
・簡潔に、第三者が読んでも理解できるようにする
```

**入力してはいけない情報：** 利用者・職員の実名・特定情報

**出力後に確認すること：**
- 事実関係が正確か担当者が確認する
- 医療・介護上の判断に関わる内容は専門家が確認する

## 5. 会議メモの要約

---

### 5-1 会議メモを要点にまとめる

**使う場面：** 会議のメモを整理・要約したいとき

**プロンプト：**
```
以下の会議メモを、要点だけにまとめてください。
・決定事項
・課題・保留事項
・次のアクション（担当部署と期限）
の形式で整理してください。

会議メモ：
〔個人名・個人情報を除いた会議メモを貼り付ける〕
```

**入力してはいけない情報：** 個人名・個人情報・機密事項

**出力後に確認すること：**
- 決定事項・アクションが正確か参加者が確認する

---

### 5-2 議事録の下書きを作る

**使う場面：** 会議の議事録を作りたいとき

**プロンプト：**
```
以下の会議メモをもとに、議事録の下書きを作成してください。
形式：
・会議名・日時・参加者（役職のみ、個人名不要）
・議題ごとの内容
・決定事項
・次回までのアクション

メモ内容：
〔個人名なしのメモを貼り付ける〕
```

**入力してはいけない情報：** 職員・利用者の個人名・個人情報

**出力後に確認すること：**
- 内容の正確さを参加者が確認する
- 公式文書として使う前に担当者が最終確認する

## 6. クイズ作成

---

### 6-1 介護・福祉クイズ

**使う場面：** 研修・勉強会でクイズを使いたいとき

**プロンプト：**
```
介護や福祉に関する〔初心者向け / 中級者向け〕クイズを〔5〕問作ってください。
選択肢を4つずつ付けて、最後に答えと解説も書いてください。
テーマ：〔例：認知症の基礎知識 / 介護保険制度 / 感染対策〕
```

**入力してはいけない情報：** 個人情報

**出力後に確認すること：**
- 専門的な内容は担当者・専門家が正確さを確認する
- 制度・法律に関わるクイズは必ず確認する

---

### 6-2 新人研修用クイズ

**使う場面：** 新人職員の研修でクイズを使いたいとき

**プロンプト：**
```
福祉・介護施設で働く新入職員向けに、業務マナーや基本ルールに関するクイズを〔3〕問作ってください。
○×形式で、答えと簡単な解説を付けてください。
テーマ：〔例：報告・連絡・相談の基本 / プライバシー保護〕
```

**入力してはいけない情報：** 個人情報・施設の内部情報

**出力後に確認すること：**
- 施設のルール・方針と一致しているか確認する

## 7. 注意喚起文

---

### 7-1 感染対策の注意喚起

**使う場面：** 感染対策の周知文を作りたいとき

**プロンプト：**
```
施設内の感染対策について、職員向けの注意喚起文を作成してください。
内容：
・手洗い・手指消毒の徹底
・マスク着用のルール

条件：
・丁寧だが、行動を促す明確な表現にする
・箇条書きを使ってわかりやすくする
```

**入力してはいけない情報：** 感染者の個人情報

**出力後に確認すること：**
- 最新の感染対策ガイドラインと一致しているか確認する
- 医療上の内容は必ず専門家が確認する

---

### 7-2 個人情報保護の周知文

**使う場面：** 個人情報の取り扱いについて職員に周知したいとき

**プロンプト：**
```

特に以下の点を強調してください：
・利用者情報の取り扱い
・SNS・スマホ使用のルール
・書類・データの管理
・外部への情報漏えい防止
条件：
・分かりやすく、具体的な行動を示す
・怖がらせすぎず、「守ることで利用者を守れる」という前向きなトーン
```

**入力してはいけない情報：** 職員・利用者の個人情報

**出力後に確認すること：**
- 施設の個人情報保護規程と一致しているか確認する
- 法的な内容は必ず担当者・専門家が確認する

## 8. 初心者向けAI練習用プロンプト

---

### 8-1 とにかく試してみる

**プロンプト：**
```
こんにちは。私は介護施設で働いています。
Geminiの使い方を練習しています。何か簡単な挨拶をしてください。
```

**狙い：** 画面操作に慣れる。AIが普通に返答することを体験する。

---

### 8-2 簡単な質問から始める

**プロンプト：**
```
「傾聴」とはどういう意味ですか？介護の現場で大切な理由も教えてください。
```

**狙い：** AIが知識を説明できることを体験する。

---

### 8-3 文章を作ってもらう

**プロンプト：**
```
利用者さんへの朝のあいさつ文を3パターン作ってください。
どれもやさしく、温かい雰囲気にしてください。
```

**狙い：** AIが複数の選択肢を出せることを体験する。

---

### 8-4 指示を追加する練習

手順：
1. まず「季節のあいさつ文を作ってください」と入力
2. 次に「もっと短く、100字以内にしてください」と追加入力
3. 「もう少し温かいトーンにしてください」と再度入力

**狙い：** 追加指示で内容を調整できることを体験する。

## 9. 安全確認用プロンプト

---

### 9-1 自分の文章にNGな情報が含まれていないか確認する

**プロンプト：**
```
以下の文章に、個人情報や機密情報が含まれていないかを確認してください。
問題があれば指摘してください。

文章：
〔確認したい文章を貼り付ける〕
```

**注意：** 確認する文章自体に個人情報が入っていないことを先に確認する。

---

### 9-2 文章のトーンに問題がないか確認する

**プロンプト：**
```
以下の文章を、利用者さんのご家族に送ることを想定してチェックしてください。
・失礼な表現がないか
・誤解を生みそうな部分がないか
・読んで不安にならないか
指摘があれば修正案も提案してください。

文章：
〔確認したい文章を貼り付ける〕
```

**出力後に確認すること：**
- AIの指摘が正しいかを人が判断する
- 最終的な判断は必ず人間が行う
