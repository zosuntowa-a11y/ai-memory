# はじめてのGemini体験研修 — 資料一式

> AIを楽しく、安全に仕事で使ってみよう

---

## 研修の概要

| 項目 | 内容 |
|------|------|
| 対象 | 福祉・介護・医療系会社の全スタッフ（AI初心者〜少し経験あり） |
| 時間 | 約60分 |
| 形式 | 参加者自身のPC/スマホでGeminiを操作しながら進める参加型研修 |
| 主なツール | Google Gemini（Google Workspaceで利用） |
| 目的 | Geminiの基本的な使い方を体験し、明日から小さな業務に活かせるようになる |

## 事前準備（担当者向け）

### 参加者への案内（1週間前まで）
- PC またはスマホを持参してもらう旨を連絡する
- Googleアカウントにログインできる状態にしておいてもらう
- Geminiの画面（gemini.google.com）を事前に開いておくよう案内すると当日スムーズ

### 会場・機材
- プロジェクターまたは大型モニター（講師の画面を映す）
- Wi-Fi環境の確認（参加者全員が同時接続できるか）
- 印刷物が必要な場合：`participant_worksheet.md` を人数分印刷

### 講師の準備
- `facilitator_script.md` を通読し、ワーク操作を自分で一度やってみる
- Geminiの動作確認（研修当日朝に必ず確認）
- 参加者人数・PCスキル感を事前に把握しておく

## 当日の進め方

```
0〜5分   導入・今日のゴール共有
5〜15分  AI・Geminiの基本説明
15〜25分 体験① 簡単な質問・クイズ
25〜40分 体験② 実務に近い文章作成
40〜50分 体験③ 指示を改善してみる
50〜55分 安全に使うための注意点
55〜60分 振り返り・共有・まとめ
```

詳細は `facilitator_script.md` を参照してください。

---

## 注意事項

- **個人情報・利用者情報はGeminiに入力しない**（氏名・住所・病歴・施設名 等）
- AIの回答は必ず人が確認してから使用する
- 法律・医療・介護の判断に関わる内容はAIに頼らない
- AIは間違えることがあります。最終責任は使う人・組織にあります
